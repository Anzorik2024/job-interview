Шпаргалка для собеседований (Frontend)

Семантический HTML — использование тегов, отражающих смысл содержимого: <header>, <article>, <nav> и т. д. Преимущества:

  • Улучшение доступности (для скринридеров)
  • Лучшая SEO-оптимизация
  • Упрощение поддержки кода

Flexbox — одномерная система раскладки (строка или столбец). Идеален для выравнивания элементов внутри контейнера.

Grid — двумерная система (строки и столбцы одновременно). Подходит для создания макетов страниц.

Event loop — механизм, позволяющий JS выполнять асинхронный код без блокировки основного потока. Этапы:

  1. Выполнение синхронного кода
  2. Помещение асинхронных задач в очередь (callback queue)
  3. Обработка событий из очереди, когда стек вызовов пуст

Типы данных:

  1. undefined — самостоятельный тип "undefined"
  2. null — исторически считается объектом (typeof null === "object"), хотя технически это отдельный тип. Это признанный баг языка.

Как они возникают:

undefined — значение, которое JavaScript присваивает автоматически:

  1. Объявленная, но не инициализированная переменная.
  2. Доступ к несуществующему свойству объекта.
  3. Параметр функции, для которого не передан аргумент.
  4. void 0 (часто используется как безопасный способ получить undefined).

    5. null — всегда задаётся программистом вручную, чтобы указать «здесь намеренно ничего нет».

Сравнение:

  1. null == undefined // true (нестрогое равенство)
  2. null === undefined // false (строгое равенство, разные типы)

Преобразование в числа:

  1. Number(null) // 0
  2. Number(undefined) // NaN
  3. null + 5 // 5
  4. undefined + 5 // NaN

В булевом контексте:

  1. !!null // false
  2. !!undefined // false

В JSON:

  • null — корректное JSON-значение: JSON.stringify({a: null}) → '{"a":null}'.
  • undefined — игнорируется (или превращается в null при замене): JSON.stringify({a: undefined}) → '{}'.
